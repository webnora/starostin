## 5. Коэффициент кластеризации

```
CK = (контексты в кластерах) / (все контексты)

DON:    CK = 65 / 220 = 0.295 (29.5%)
WYRCEAN: CK = 28 / 140 = 0.200 (20.0%)
LECGAN: CK = 30 / 59  = 0.508 (50.8%) ⭐
FREMMAN: CK = 35 / 96  = 0.365 (36.5%)
```

**Лидер:** LECGAN с 50.8% кластеризации

**Объяснение:** Конкретное значение "класть" создает более устойчивые паттерны

## 11. Практические рекомендации

### Для выбора глагола для анализа:

1. **Минимум 100 контекстов** для надежной кластеризации
2. **Предпочтение конкретным глаголам** (как LECGAN)
3. **Избежание устойчивых формул** (как у WYRCEAN)
4. **Баланс между широкозначностью и конкретностью**

### Для параметров HDBSCAN:

| Размер корпуса | min_cluster_size | min_df |
|----------------|------------------|--------|
| 50-100 | 6-8 | 1-2 |
| 100-150 | 8-10 | 2 |
| 150-250 | 10-15 | 2-3 |

### Для интерпретации:

1. **Процент шума > 70%** → рассматривать как широкозначный глагол
2. **Процент шума < 50%** → конкретный глагол с устойчивой семантикой
3. **Количество кластеров ≥ 4** → семантически диверсифицированный глагол

## 14. Заключение

### Ключевые находки:

1. **Широкозначные глаголы (DON)** создают больше семантических кластеров (5)
2. **Конкретные глаголы (LECGAN)** показывают лучшую кластеризацию (50.8%)
3. **Размер корпуса** не является главным фактором качества
4. **Устойчивые формулы** (как у WYRCEAN) повышают процент шума
5. **Этически окрашенные глаголы (FREMMAN)** занимают промежуточное положение

### Гипотезы:

✅ **Подтверждено:** Широкозначность → больше кластеров
✅ **Подтверждено:** Конкретность → меньше шума (за исключением WYRCEAN)
❌ **Опровергнуто:** Размер корпуса → лучшая кластеризация

### Рекомендации для будущих исследований:

1. Использовать глаголы с конкретной семантикой для лучшей кластеризации
2. Минимум 100 контекстов для надежности
3. Учитывать устойчивые формулы при выборе глагола
4. Экспериментировать с параметрами HDBSCAN для разных размеров корпуса
