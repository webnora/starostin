## 4. Cluster Analysis

### 4.1. Cluster 0: Perfektive-Divine Action (23 контекста, 10,2%)

**Доминирующие формы:** *gedon* (совершенное действие), *do* (императив)

**Семантика:**
- Совершенные действия Бога
- Императивы с обращением к divine agency
- СCompleted actions with divine agency

**Репрезентативные примеры:**

1. *þe ge him to dāre gedōn motan*
   ```
   «что вы ему к мести [правосудию] должны сделать»
   ```

2. *Dryhten ariseð he on eorðan dō ealle hale*
   ```
   «Господь восста он на земле сделал все целым»
   ```

3. *Gehet Dāvide swa he him dyde*
   ```
   «Пообещал Давиду, как он ему сделал [сдержал обещание]»
   ```

**Лексическое окружение:**
- *Dryhten* «Господь»
- *duguð* «доблесть, польза»
- *gedōn* «совершить, сделать (перфект)»

---

### 4.2. Cluster 1: Prayer-Supplication (30 контекстов, 13,3%)

**Доминирующие формы:** *dō* (императив в молитвах)

**Семантика:**
- Молитвенные обращения к Богу
- Просьбы о спасении, исцелении, защите
- Performatives в религиозных контекстах

**Репрезентативные примеры:**

1. *Dō me halne, Dryhten*
   ```
   «Сделай меня здоровым/целым, Господи»
   ```

2. *Dryhten God, dō mē þīne mýcle mildheortnesse*
   ```
   «Господи Бог, сделай мне Твою великую милость»
   ```

3. *Dō mē cwicne, Dryhten*
   ```
   «Сделай меня живым, Господи»
   ```

4. *Þū Dryhten mīn, dō þū halne mē*
   ```
   «Ты, Господь мой, сделай меня здоровым/целым»
   ```

**Лексическое окружение:**
- *Dryhten* «Господь»
- *hal* «здоровый, святой, целостный»
- *mildheortnes* «милость»
- *cwic* «живой»

## 6. Diachronic Interpretation

### 6.1. PIE *dhe- → PGmc *dōną → OE *dōn*

```
PIE *dhe- "ставить, помещать"
          │
          ▼
PGmc *dōną "делать"
          │
    ┌─────┴─────┐
    ▼           ▼
OE *dōn*    OHG *tuōn*
(VII–XI вв.)  (IX в.)
    │           │
    ▼           ▼
Широкозначность  Широкозначность
+ сакральная    + сакральная
специализация   специализация
```

### 6.2. Typological Insights

**Почему OE *dōn* шире, чем OHG *tuōn*?**

**Гипотеза 1: Различия в переводческой традиции**
- OHG Tatian — последовательный перевод латинского оригинала
- OE corpus — разнообразие жанров, включая оригинальную поэзию

**Гипотеза 2: Грамматикализация**
- OE *dōn* раньше начинает использоваться как вспомогательный глагол
- Примеры: periphrastic constructions, future forms

**Гипотеза 3: Контактное влияние**
- OE контактировал с Celtic substratum
- Различные стратегии перевода религиозных текстов

## 7. Key Findings

### 7.1. ✓ Широкозначность — архаичная черта

**Аргументы:**
1. **76,6% шума** в OE (ещё больше, чем 48,4% в OHG)
2. **Континуум значений** от каузатива до перформативов
3. **Отсутствие четких кластеров** — Silhouette ~0,28

**Вывод:** Широкозначность проявляется **уже в ранних периодах** (VII–IX вв.), что указывает на архаичный характер или раннее расширение в прогерманский период.

### 7.2. ✓ Сакральная специализация — разная в OE и OHG

| Язык | Тип сакральной специализации |
|------|------------------------------|
| **OE** | Молитвенные performatives (*dō me halne* «сделай меня целым») |
| **OHG** | Коллокация с существительным (*riuwa tuōn* «творить покаяние») |

**Вывод:** Различные стратегии освоения сакральной сферы:
- OE: императивы в молитвах (direct address)
- OHG: коллокации с религиозной лексикой (nominal compounds)

### 7.3. ✓ Грамматикализация раньше в OE

**Признаки:**
- Широкая семантика (76,6% шума)
- Употребление в перифразах
- Будущее время и модальные конструкции

**Вывод:** OE *dōn* раньше OHG *tuōn* начинает путь к auxiliary status.

## 9. Conclusion

### 9.1. Main Findings

1. ✓ **Широкозначность *dōn* в OE выражена сильнее**, чем *tuōn* в OHG (76,6% vs 48,4% шума)

2. ✓ **Сакральная специализация** в обоих языках, но **разных типов**:
   - OE: молитвенные императивы (performatives)
   - OHG: коллокации (lexical compounds)

3. ✓ **Архаичный характер** широкозначности подтверждается:
   - Проявляется уже в VII–IX вв.
   - Сравнимые явления в других и.-е. языках

4. ✓ **Грамматикализация** *dōn* в OE начинается раньше, чем *tuōn* в OHG

### 9.2. Typological Significance

**Значение для PIE reconstruction:**

- PIE *dhe- имел широкое значение «ставить → делать → совершать»
- Расширение до сакральной сферы — и.-е. тенденция
- Грамматикализация — независимый процесс в отдельных языках
