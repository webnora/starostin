## 🔬 КЛЮЧЕВЫЕ ОТКРЫТИЯ

### 1. Диахроническая эволюция

**Тренд:** От религиозного к светскому (31% → 7%)

```
IV век:        Готский τaujan         → 31% divine (максимум)
VIII-XI век:   Др.-англ. don          → 13% divine (спад)
X-XIII век:    MHG tuon               → 29% divine (ренессанс)
XI-XIV век:    Др.-исланд. dœ/gera    → 7-13% divine (минимум)
```

**Причина:** Смена типов текстов (Библия → саги)

### 2. Лексикальная дифференциация в древнескандинавском

**Уникальное явление:** Два глагола "делать" от разных корней:

| Глагол | Корень | Вхождений | Статус |
|--------|--------|-----------|--------|
| **dœ** | *dōjan* | 22 (2.4%) | ✗ Исчез (архизм) |
| **gera** | *garwijan* | 904 (97.6%) | ✓ Выжил (совр. исл.) |

**Соотношение:** 1:41 (gera в 41 раз частотнее!)

**Вывод:** Gera был продуктивным глаголом с полной парадигмой, dœ — архаизм с одной формой (dyr).

### 3. Уникальные черты каждого языка

| Язык | Уникальная черта | Пример |
|------|------------------|--------|
| Готский | Метафора дерева | "Доброе дерево творит добрые плоды" |
| Др.-англ. | Сравнения | "swa swa swa" (так же, как) |
| MHG | Совершённый | getan (108, 25% всех) |
| Др.-исланд. | Два глагола | dœ vs gera |

### 4. Религиозный фактор

**Корреляция:** Тип текста определяет семантику глагола

- Религиозные тексты → высокий % divine (31% в готском)
- Светские тексты → низкий % divine (7% в др.-исланд.)

**Вывод:** Семантика глагола контекстуально зависима

## 📈 МЕТОДОЛОГИЯ

### Унифицированный подход для всех 4 языков:

```
1. Извлечение текста → plain text
2. Поиск форм глагола → regex patterns
3. TF-IDF векторизация → max_features=80, min_df=2
4. K-Means кластеризация → n_clusters=6, random_state=42
5. t-SNE визуализация → perplexity=25, max_iter=1000
6. PCA визуализация → 2 компоненты
7. Ручная категоризация → Divine, Human, Teaching, etc.
```

### Результаты кластеризации:

| Язык | Кластеров | PCA variance | Стабильность |
|------|-----------|--------------|--------------|
| Готский | 6 | 60-70% | Высокая (четкие Divine/Human) |
| Др.-англ. | 6 | 55-65% | Средняя (перемешанные) |
| MHG | 6 | 65-75% | Высокая (Divine + Perfect) |
| Др.-исланд. | 6 | 40-50% | Низкая (мало данных) |
