## 🔬 Основные результаты анализа tuon

### 6 семантических кластеров:

| Кластер | Размер | Семантика |
|---------|--------|-----------|
| 0 | 71 | "wir tuon" — коллективное "мы делаем" |
| 1 | 56 | "ich tuon" — личное "я делаю" |
| 2 | 106 | Общие контексты |
| 3 | 37 | getan — перфект "сделано" |
| 4 | 85 | Отрицание: "ne tuon niht" |
| 5 | 78 | Перфект: "daz getan" — "что сделано" |

### Распределение форм:
- **tuon** (инфинитив/наст.): 322 (74.4%) — доминирует
- **getan** (перфект): 108 (24.9%)
- **gedan** (перфект вариант): 2 (0.5%)
- **tuo** (наст. 3л.): 1 (0.2%)

### Ручная категоризация:
- **Divine** (божественное): 125 (28.9%) — самая крупная!
- Other (прочее): 240 (55.4%)
- Good_deeds (добрые дела): 56 (12.9%)
- Command (повеления): 6 (1.4%)
- Battle (битвы): 3 (0.7%)
- Evil_deeds (зло): 2 (0.5%)
- Teaching (учение): 1 (0.2%)

### Ключевые выводы:

1. **tuon** — самый религиозно нагруженный из трёх языков (28.9% divine)
2. **Высокая частотность перфекта** getan (33.2%) — уникальная особенность
3. **Выраженное первое лицо** ("ich tuon") в религиозных контекстах
4. Форма не определяет смысл — tuon во всех кластерах
5. Корпус более однороден (преимущественно религиозные тексты)

## 🚀 Использование

### Запуск анализа:
```bash
python3 tuon_analysis.py
```

Требования:
- Python 3.9+
- numpy, matplotlib, sklearn
- Исходные файлы в `../MHG/`

### Формат исходных файлов:
- Скобочная нотация с POS-тегами
- Пример: `(PRO^N^SG Ih=ich)` — лемма "ich", форма "Ih"
- ID предложений для разделения текста
