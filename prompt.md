Ты — эксперт по компьютерной лингвистике и Python. Напиши код для семантического анализа древнеанглийского глагола "dōn" методом PPMI + SVD.

### Входные данные:
У меня есть 226 контекстов употребления глагола "dōn" (древнеанглийский). Каждый контекст — это строка с предложением, где встречается глагол. Контексты извлечены с окном ±5 слов (т.е. глагол и по 5 слов слева и справа).

Формат данных: простой текстовый файл, каждая строка — один контекст.

### Что нужно сделать:

#### Шаг 1. Загрузка и предобработка
- Загрузить файл с контекстами
- Токенизировать каждый контекст (разбить на слова)
- Построить словарь уникальных слов (игнорируем частотность, но можно отфильтровать слова, встречающиеся меньше N раз, например, N=2)
- Для каждого контекста построить "мешок слов" (bag of words)

#### Шаг 2. Построение матрицы PPMI
- Построить матрицу совместной встречаемости слов в пределах одного контекста (окно = весь контекст, т.к. контексты уже обрезаны до ±5)
- Размер матрицы: V × V, где V — размер словаря
- Значение [i][j] = сколько раз слово i встречается в одном контексте со словом j
- Преобразовать матрицу совместной встречаемости в PPMI (Positive Pointwise Mutual Information) по формуле:

PPMI(w, c) = max( log2( P(w,c) / (P(w) * P(c)) ), 0 )

где:
- P(w,c) = count(w,c) / total_pairs
- P(w) = count(w) / total_words
- P(c) = count(c) / total_words
- total_pairs = сумма всех count(w,c) в матрице
- total_words = общее количество вхождений слов в корпус

#### Шаг 3. SVD (Singular Value Decomposition)
- Применить SVD к PPMI-матрице
- Сократить размерность до 100-300 компонент (можно выбрать 200 как компромисс)
- Получить низкоразмерные векторы для каждого слова

#### Шаг 4. Визуализация
- Взять векторы только для формы "dōn" (или для всех форм: dyde, dydon, dō, если они есть в словаре)
- Применить PCA или UMAP (лучше UMAP) для визуализации в 2D
- Построить scatter plot, где каждая точка — это употребление глагола (контекст)
- Точки раскрасить по кластерам (можно пока просто одним цветом, а если получится — применить HDBSCAN к SVD-векторам)
