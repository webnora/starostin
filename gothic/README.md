# Gothic Linguistic Analysis

Анализ готского языка на материале Готской Библии (Streitberg, 1919)

## 📁 Содержимое

### Корпус
- **gotica.txt** (509 KB) — Готская Библия, издание Streitberg (1919)
  - 4340 строк текста
  - Проект Wulfila (University of Antwerp)

### Скрипты анализа

#### taujan_analysis.py (11 KB)
Базовый анализ глагола *τaujan* (делать/творить):
- Поиск всех форм глагола
- Co-occurrence матрица
- PPMI (Positive Pointwise Mutual Information)
- PCA визуализация

#### taujan_simple.py (4.9 KB)
Упрощённый анализ для быстрой проверки:
- TF-IDF векторизация
- K-Means кластеризация (5 кластеров)
- t-SNE визуализация

#### taujan_full_analysis.py (18 KB)
Полный анализ с кластеризацией:
- TF-IDF (80 признаков)
- K-Means (6 кластеров)
- t-SNE + PCA визуализации
- Ручная категоризация по контекстуальным маркерам
- POS-анализ частей речи
- Divine vs Human разделение

#### taujan_deep_analysis.py (19 KB)
Расширенная версия (экспериментальная):
- Дополнительные метрики
- Hierarchical clustering
- Агрегированная визуализация

## 🔬 Основные результаты анализа τaujan

### 6 семантических кластеров:

| Кластер | Размер | Семантика |
|---------|--------|-----------|
| 0 | 23 | Сравнение: "также делать, как другие" |
| 1 | 30 | Метафора дерева: плоды добрые/злые |
| 2 | 26 | Отрицание: "не делать ничего" |
| 3 | 27 | Вопросы и волеизъявление |
| 4 | 22 | Императив: обращение к людям |
| 5 | 12 | Учение: слушание слов Божьих |

### Ручная категоризация:
- **Divine** (43) — божественные действия
- **Teaching** (17) — учение/заповеди
- **Creation** (11) — метафора дерева
- **Good_deeds** (8) — добрые дела
- **Obedience** (8) — повиновение
- **Evil_deeds** (3) — грех
- **Miracles** (3) — чудеса
- **Other** (47) — прочее

### Ключевые выводы:

1. **τaujan** — "семантический хамелеон": смысл определяется только контекстом
2. **3 измерения**: божественное vs человеческое, добрые vs злые дела, сравнение
3. **Метафора дерева** — отдельная устойчивая семантическая область
4. **Форма не = смысл**: taujiþ встречается во всех кластерах
5. Значение τaujan — типичный глагол общего действия

## 🚀 Использование

```bash
python3 taujan_full_analysis.py
```

### Запуск упрощённого анализа:
```bash
python3 taujan_simple.py
```

### Запуск базового анализа:
```bash

```

## 📊 Метрики

- **Корпус**: 140 вхождений τaujan
- **Признаки**: TF-IDF, 80 измерений
- **Кластеризация**: K-Means, n=6
- **Визуализация**: t-SNE (perplexity=25), PCA
- **Формы глагола**: 9 форм (taujan, taujis, taujiþ, taujaiþ, taujand, taujands, gataujan, gataujiþ, taujaid)
