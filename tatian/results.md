# Семантическая структура глагола *tuōn* в древневерхненемецком языке:
## корпусный анализ на основе материала «Диатессарона» Татиана

---

## 1. Введение

Настоящее исследование посвящено компьютерному моделированию семантической структуры широкозначного глагола *tuōn* «делать, творить» в древневерхненемецком языке (IX в.) с использованием методов дистрибутивной семантики и кластерного анализа.

В качестве материала исследования используется **Tatian Corpus** — электронный корпус древневерхненемецкого перевода «Диатессарона» Татиана, выполненного в монастыре Фульда в первой половине IX века. «Диатессарон» (лат. «через четыре») — гармония четырёх евангелий, созданная сирийским автором Татианом во II веке н.э., представляет собой уникальный текст, объединяющий повествования Матфея, Марка, Луки и Иоанна в единое согласованное целое.

## 3. Методология исследования

### 3.1. Объект исследования

**Лексема *tuōn* (древневерхненемецкий)** — глагол с широкой семантической структурой, охватывающий значения:

- *делать, совершать* (действие вообще)
- *творить, создавать* (божественное творение)
- *поступать, вести себя* (поведение)
- *каяться, творить покаяние* (религиозный контекст)
- *действовать, оказывать воздействие* (каузация)

**Праславянский изоглосс**: *dělati* «делать» (родственно через и.-е. *deh₁-*)

### 3.2. Методы анализа

Исследование проводилось в три этапа:

#### Этап 1: Корпусное извлечение
- Поиск всех форм глагола *tuōn* в корпусе
- Извлечение контекстного окна (±5 токенов)
- Выделение 62 вхождений в 13 словоформах

#### Этап 2: Векторное представление
- **TF-IDF векторизация** (unigrams + bigrams)
- Матрица: 62 × 381 признаков
- Нормализация L2

#### Этап 3: Кластеризация
- **HDBSCAN** (Hierarchical Density-Based Spatial Clustering)
- Min cluster size: 6
- Metric: Euclidean
- Cluster selection method: EOM (Excess of Mass)

#### Этап 4: Визуализация
- **UMAP** (Uniform Manifold Approximation and Projection)
- n_neighbors: 15
- min_dist: 0.1
- Metric: euclidean

#### **Тенденция А: Профанно-этическое употребление**
*(11 контекстов; 17,7% от выборки)*

⚠️ **Примечание:** Данная группа не образует компактный кластер, а представляет собой семантическую тенденцию.

**Доминирующие формы:** tuot, tuont, tuon (настоящее время, индикатив)

**Семантическое ядро:**
Позитивно оценочные действия, совершаемые праведниками или Богом. Контексты описывают морально одобряемую деятельность, благотворительность, исполнение божественной воли.

**Репрезентативные примеры:**

1. *thie sunta tuot*
   ```
   «святые делают [благое]»
   T_217__17_epsilon
   ```

2. *thaz tuont suntige mán*
   ```
   «что делают праведные люди»
   T_066__05_beta
   ```

3. *thie íu uuola tuont*
   ```
   «которые вам хорошо делают [творят добро]»
   T_066__03_beta
   ```

4. *eno ni+ tuont thaz heidane man*
   ```
   «ещё не делают это язычники [эти добрые дела]»
   T_066__12_beta
   ```

5. *thaz íu man tuon*
   ```
   «чтобы вам человек сделал [добро]»
   T_073__17a_beta
   ```

**Семантическая характеристика:**
Данный кластер объединяет контексты, где *tuōn* обозначает **позитивное социально одобряемое действие**, направленное на благо другого субъекта. Глагол используется в descriptions of:
- праведного поведения (ср. *suntiga mán* «праведные люди»)
- благотворительности (ср. *uuola tuont* «творят добро»)
- следования божественным заповедям

**Лексическое окружение:**
- *suntiga* «праведный»
- *uuola* «хорошо, добро»
- *heidane* «языческий» (в негативных контекстах)
- *man* «человек»

#### **Кластер 1: «Покаяние и искупление»**
*(21 контекст; 33,9% от выборки)*

**Доминирующие формы:** tatin, tatun (прошедшее время, конъюнктив)

**Семантическое ядро:**
Религиозно-ритуальный комплекс покаяния, отпущения грехов и духовного очищения. Контексты описывают сакральное действие раскаяния, часто в сочетании с лексемой *riuua* «покаяние».

**Репрезентативные примеры:**

1. *thaz sie riuua tatin*
   ```
   «что они каялись [творили покаяние]»
   T_081__09-10_beta
   ```

2. *tuot riuua*
   ```
   «твори покаяние [качайся]»
   T_044__01_alpha
   ```

3. *uuanta sie riuua tatun*
   ```
   «ибо они каялись [творили покаяние]»
   T_093__05_beta
   ```

4. *uúaz sie tatin / themo heilante*
   ```
   «что они каялись перед Спасителем»
   T_107__02-03_beta
   ```

5. *thaz sie inan ougazorohtan ni+ tatin*
   ```
   «что они его не признавали [не совершали над ним обряд признания]»
   T_107__06_beta
   ```

6. *oba ir riuua ni tuot*
   ```
   «если они не каются [не творят покаяния]»
   T_163__07_gamma
   ```

**Семантическая характеристика:**
Данный кластер демонстрирует специализацию глагола *tuōn* в **сакрально-ритуальной сфере**. В сочетании с существительным *riuwa* (покаяние) глагол образует устойчивый коллокационный комплекс *riuwa tuon/tān* «творить покаяние», восходящий к латинскому *paenitentiam agere*.

**Лексическое окружение:**
- *riuwa* «покаяние» (ключевой коллокат)
- *heilant* «Спаситель»
- *ougazorohtan* «признавать, исповедовать»
- *abrahames* «Авраама» (в контексте веры)

#### **Переходная зона: Разнородные употребления**
*(30 контекстов; 48,4% от выборки)*

⚠️ **Примечание:** Это "шумовые" точки для HDBSCAN — то есть контексты, которые не могут быть надежно отнесены ни к одной компактной группе. С лингвистической точки зрения это не "шум", а **континуум переходных значений**.

**Характеристика:**
Оставшаяся половина вхождений образует переходную зону между двумя выделенными семантическими тенденциями. Эти контексты характеризуются:

1. **Модальными употреблениями** (сослагательное наклонение)
2. **Перформативными контекстами** (императивы, побуждения)
3. **Сложными синтаксическими конструкциями**
4. **Метафорическими употреблениями**

**Репрезентативные примеры:**

- *truhtin heilan / tuo mih* «Господи, спаси / исцели меня» (модальное значение «твори, сделай»)
- *uuas sculun uuir tuon* «что нам должно делать» (этический вопрос)
- *ther thie habe muos tuo selbsama* «кто должен иметь, делает сам» (рефлексивное употребление)
- *thanne thú tuos elimosinam* «тогда ты подашь милостыню» (ритуализированное действие)

## 5. Лингвистическая интерпретация

**Интерпретация:**

1. **Отсутствие четких границ:** Высокий процент "шума" (48,4%) указывает на плавные переходы между значениями
2. **Тенденции, а не кластеры:** Речь идет о семантических тенденциях, а не о дискретных кластерах
3. **Широкозначность:** Глагол *tuōn* в исследуемом периоде — типичная широкозначная лексема с размытыми границами значений

### 5.2. Факторы кластерообразования

#### Фактор 1: Темпоральность
- **Настоящее время** → Кластер 0 (актуальное действие)
- **Прошедшее время** → Кластер 1 (завершённый ритуал)

#### Фактор 2: Акциональность
- **Дуративные действия** → Кластер 0 (процесс делания)
- **Семельфактивы** → Кластер 1 (ритуальный акт)

#### Фактор 3: Лексическая коллокация
- **Коллокация с *uuola* «хорошо»** → Кластер 0
- **Коллокация с *riuwa* «покаяние»** → Кластер 1

#### Фактор 4: Субъект действия
- **Человеческий агент** → Кластер 0
- **Сакральный субъект** → Кластер 1

### 5.3. Типологическая перспектива

### 5.4. Диахроническая перспектива

Выявленная структура соответствует раннему этапу семантического развития глагола *tuōn* → современный *tun*:

1. **IX век (Tatian)**: дифференциация по сферам употребления (сакральная vs профанная)
2. **XI–XV века**: дальнейшая специализация (ср. средневерхненемецкое *tūn*)
3. **XVI–XXI века (немецкий)**: десемантизация auxiliarisation (*tun* как вспомогательный глагол)

## 6. Выводы

1. **Корпусная валидация**: Метод HDBSCAN + UMAP успешно применим для семантической кластеризации лексики древних германских языков, даже при ограниченном корпусе (62 вхождения).

2. **Биполярная структура**: Глагол *tuōn* в «Диатессароне» обнаруживает два семантических полюса:
   - **Профанный**: добродетельные действия (17,7%)
   - **Сакральный**: покаяние и искупление (33,9%)

3. **Высокая вариативность**: Почти половина вхождений (48,4%) образует переходную зону, что свидетельствует о широкозначности глагола в исследуемый период.

4. **Латинское влияние**: Специализация в сфере покаяния (*riuwa tuon*) является калькой с латинского *paenitentiam agere*, что подтверждает гипотезу о контактном влиянии христианской лексики на древневерхненемецкий.

5. **Перспективы исследования**: Данные результаты могут быть расширены через:
   - Сравнительный анализ с другими древнегерманскими корпусами
   - Диахроническое прослеживание семантической структуры (*tuōn* → MHG *tūn* → NHG *tun*)
   - Исследование коллокационных паттернов (объекты, актанты, адвербиалы)
