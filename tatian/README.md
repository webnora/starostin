# Исследование глагола *tuōn* в корпусе Татиана

## Описание проекта

Компьютерный анализ семантической структуры широкозначного глагола *tuōn* «делать, творить» в древневерхненемецком языке (IX век) на основе корпуса «Диатессарона» Татиана.

## Основные результаты

### Количественные показатели
- **Всего вхождений:** 62
- **Словоформ:** 13
- **Кластеров HDBSCAN:** 2 (низкого качества)
- **Шумовых точек:** 30 (48,4%)

### Важное примечание о кластеризации

⚠️ **Результаты кластеризации следует интерпретировать с осторожностью:**

- **48,4% контекстов отнесены к шуму** — это указывает на то, что четкая кластерная структура не выявлена
- **Визуализация UMAP** показывает выраженное рассеяние точек без компактных групп
- **Silhouette score ≈ 0,34** — mediocre качество кластеризации

### Интерпретация результатов

Вместо четко разделенных кластеров, наблюдается **континуум семантических значений** с двумя тенденциями:

1. **Тенденция А (≈18%)** — профанные действия
   - Позитивно оценочные действия в мирских контекстах
   - Пример: *thie sunta tuot* «святые делают [благое]»

2. **Тенденция Б (≈34%)** — сакральные действия
   - Религиозные контексты, часто с лексемой *riuva* «покаяние»
   - Пример: *thaz sie riuva tatin* «что они каялись»

3. **Переходная зона (≈48%)** — смешанные контексты
   - Модальные употребления
   - Перформативы и побуждения
   - Метафорические употребления

### Ключевые выводы
- **Широкозначность**: *tuōn* демонстрирует высокую вариативность без четких границ между значениями
- **Континуум**: семантическая структура представляет собой плавный континуум, а не дискретные кластеры
- **Латинское влияние**: специализация в сфере покаяния (*riuva tuōn*) — результат калькирования с латинского
- **Методологический вывод**: для подобных лексем требуются более тонкие методы анализа (например, анализ коллокаций, построение семантических сетей)

## Методы

```
Корпус (2030 XML)
    ↓
Извлечение tuōn (62 контекста, окно ±5)
    ↓
TF-IDF векторизация (62 × 381 матрица)
    ↓
HDBSCAN кластеризация (min_cluster_size=6)
    ↓
UMAP визуализация (n_neighbors=15)
```

## Репликация исследования

### Требования
- Python 3.9+
- numpy, scikit-learn, hdbscan, umap-learn, matplotlib

```bash
# 1. Распаковать корпус

# 2. Запустить анализ
python3 tuon_hdbscan_analysis.py

# 3. Результаты
# ├── tuon_hdbscan_umap.png (визуализация)
# └── tuon_hdbscan_results.txt (детали кластеров)
```
